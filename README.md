
# BRS (Burlap Rating System) — Сервис оценки канализационных люков

[![Secret Scanning (TruffleHog)](https://github.com/slolvin/BRS/actions/workflows/trufflehog.yml/badge.svg)](https://github.com/slolvin/BRS/actions/workflows/trufflehog.yml)

Платформа для фанатов урбанистики, промышленного дизайна и необычного хобби. Помогаем находить, каталогизировать и оценивать люки по всему миру.

## 🚀 О проекте

Каждый канализационный люк — это произведение уличного искусства. BRS собирает базу люков, классифицирует их по дизайну, эпохе, состоянию и сохраняет их точную геолокацию.

### Компоненты системы (в активной разработке 🛠️)
* **iOS App:** Мобильное приложение для фотофиксации и быстрой оценки прямо на прогулке.
* **Web Frontend:** Интерактивная карта мира с фильтрами, рейтингами и личными кабинетами исследователей.
* **Backend:** API для синхронизации данных, хранения медиафайлов и расчета глобального рейтинга.

## 🎯 Ключевые фичи

* **Сканирование и GPS:** Автоматическая привязка люка к карте по геопозиции фото.
* **Система рейтингов:** Оценка от 1 до 5 звезд по уникальности, сохранности и исторической ценности.
* **Категории:** Сортировка по типам (дождевая, кабельная, водопроводная) и заводам-изготовителям.
* **Профили исследователей:** Достижения, статистика находок и топ-хантеров.

## 🛠️ Стек технологий

* **iOS:** Swift, SwiftUI
* **Backend:** Python
* **Database:** PostgreSQL
