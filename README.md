
# 🍹 BRS (Bar Rating System) — Платформа поиска и оценки крафтовых баров

[![Secret Scanning (TruffleHog)](https://github.com/slolvin/BRS/actions/workflows/trufflehog.yml/badge.svg)](https://github.com/slolvin/BRS/actions/workflows/trufflehog.yml)
[![Docker Security Scan (Trivy)](https://github.com/slolvin/BRS/actions/workflows/trivy.yml/badge.svg)](https://github.com/slolvin/BRS/actions/workflows/trivy.yml)

Платформа для фанатов барной культуры, ценителей крафта и любителей находить уникальные заведения. Помогаем каталогизировать бары, оценивать напитки и строить интерактивные карты заведений. BRS объединяет базу локаций, классифицирует меню по типам, оценкам и сохраняет точную геолокацию для быстрого поиска лучших коктейлей или пива поблизости.

---

## 🧭 Ключевые возможности системы

*   **📍 Интерактивная карта заведений:** Визуализация барных маркеров на карте (Leaflet / MapKit) с фильтрацией по городам и геопозиции.
*   **⭐ Комплексный рейтинг:** Динамический пересчет рейтинга баров на основе пользовательских оценок конкретных напитков.
*   **📱 QR-Чекины и валидация:** Быстрое подтверждение присутствия в баре через встроенный сканер QR-кодов в Swift-приложении с ограничением по времени действия сессии.
*   **👤 Профили исследователей:** Личная история выпитого (`drunk_history`), журнал действий (`ActionLog`) и индивидуальная статистика активности.
*   **🔒 Безопасность данных (Apple Privacy):** Встроенная система полного безвозвратного удаления аккаунта и связанных логов по первому требованию App Store.

## 🛠️ Архитектура и Стек технологий

Проект спроектирован по модульному принципу и развернут в изолированных контейнерах для обеспечения легкого масштабирования:

*   **iOS Client:** Swift 5, SwiftUI, Combine (Архитектура MVVM, менеджер авторизации на синглтонах, сетевой слой на Async/Await, обработка сессионных ошибок 401).
*   **Web Frontend:** Python, Flask, Jinja2, Bootstrap 5 (Адаптивная верстка с поддержкой динамической смены тем и умным распознаванием мобильных клиентов).
*   **Backend API:** Flask RESTful, WSGI-сервер Gunicorn (Production-режим), аутентификация на базе JWT-токенов (PyJWT).
*   **Database:** PostgreSQL 14, SQLAlchemy ORM, Flask-Migrate (Alembic). Настроены строгие каскадные удаления на уровне таблиц базы данных (`ondelete="CASCADE"`).
*   **Infrastructure:** Nginx (Reverse Proxy), Certbot (Автоматический выпуск и обновление SSL-сертификатов Let's Encrypt), Mailpit (Локальный SMTP-тестировщик почты), Adminer (Управление СУБД).

## 🚀 Быстрый запуск (Локальная разработка)

Проект полностью готов к бесшовному локальному запуску. Код синхронизируется «на лету» благодаря Docker Volumes, а Flask запущен в режиме дебага.

1. Склонируйте репозиторий и перейдите в корень:
   ```bash
   git clone https://github.com/slolvin/BRS.git
   cd brs
   ```
2. Создайте локальный файл `.env` на основе примера из `.env.example`:
   ```bash
   POSTGRES_USER=postgres
   POSTGRES_PASSWORD=example
   POSTGRES_DB=postgres
   SECRET_KEY=dev_secret_key_123
   ```
3. Запустите Docker Compose:
   ```bash
   docker compose up --build
   ```
   *   **Web-интерфейс & API:** `http://localhost:8000`
   *   **Панель Adminer (СУБД):** `http://localhost:8081`
   *   **Интерфейс Mailpit (Почта):** `http://localhost:8085`

## 🌐 Развертывание на боевом сервере (Production)

Для продакшена проект автоматически перестраивается: отключаются volumes, порты Adminer/Mailpit закрываются от интернета, Flask запускается через многопоточный **Gunicorn**, а трафик проксируется через **Nginx с HTTPS**.

Деплой и бэкап базы данных перед обновлением выполняются одной командой с вашего компьютера:
```bash
./deploy.sh
```
Для ручного применения миграций на сервере используйте:
```bash
./migrate.sh
```
