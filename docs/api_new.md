## 👤 Пользователи (Users)

### `POST /auth/register`
**Статус:** ✅ Готово
Регистрация нового пользователя.

<details>
<summary>Посмотреть детали</summary>

**Request Body:**
```json
{
  "username": "string",
  "email": "string",
  "password": "string"
}
```

**Response (201 Created):**
```json
{
  "id": "uuid",
  "message": "User created successfully"
}
```
</details>

### `POST /auth/login`
**Статус:** ⚠️ В разработке (логика JWT готова, не хватает валидации)
Вход в систему.

## 📦 Bar (Bar)

### `GET /bars`
**Статус:** ✅ Готово
Получение списка всех баров.

**Query Params:**
- `limit` (int) — количество (default 10)
- `offset` (int) — смещение
- `range` (int) - радиус

**Response (200 OK):**
```json
[
  {
    "id": 1,
    "title": "Example"
  }
]
```

### `POST /bars`
**Статус:** ✅ Готово
Создание нового бара.
